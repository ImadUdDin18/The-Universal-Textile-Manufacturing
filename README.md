# The Universal Textile Manufacturing Sdn Bhd

A modern, high-performance E-Commerce and B2B Wholesale Web Application for **The Universal Textile Manufacturing Sdn Bhd**, headquartered at Menara City One, Kuala Lumpur, Malaysia.

## 🌟 Key Features
- **Comprehensive Fabric Catalog**: Filter by GSM weight, fiber family, weave, colorway, and price per meter.
- **B2B Wholesale Tiered Discounts**: Automated volume discount engine (-10% to -30%) with real-time weight and container roll calculator.
- **Sample Swatch Ordering**: Physical fabric sample order workflow alongside bulk bolt purchasing.
- **Multi-Currency & Multilingual**: Live currency conversion (MYR, USD, EUR, GBP, SGD, PKR) and multi-language support (English, Bahasa Melayu, Urdu).
- **Shipment Telemetry & Tracking**: Real-time order tracking from loom inspection to doorstep delivery.
- **Admin Inventory Portal**: Stock adjustments, RFQ quotation management, and dynamic pricing controls.
## 🛠️ Tech Stack
- **Frontend**: React 18, TypeScript, Vite
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
